daVinci Xi® Instrument Reprocessing System (DVX - IRS) - Master's Thesis (10/10)

This virtual environment is the most comprehensive among all the projects listed here. It has been developed to simulate the complete reprocessing of a DaVinci Xi® surgical system robotic instrument and includes the cleaning, drying, and lubrication processes, with visual and auditory feedback to enable safe, autonomous learning. Additionally, it is linked to a web application that allows instructors and users to access both individual and general performance metrics, supporting personalized monitoring and objective evaluation of progress. Together, these tools offer an innovative solution that enhances hospital safety and efficiency while integrating emerging technologies into healthcare personnel training.

Robotic instrument - Large Needle Driver (8mm)

The robotic instrument to be reprocessed in this project would be a Large Needle Driver (8mm). Server-side Application

Both users and isntructors can use their credentials to access a web application hosted in the servers of the hospital.

Users will be able to check their own performance metrics, which feature their last ten attemps, with six different graphs about their performance in these attempts; as well as a summary of their best attempts of all time.

Instructors will be able to view the performance metrics of each user, featuring the same information as in each of their user pages. Additionally, they will be able to access a series os statistics about the general performance of all users.

Validation of the Project

Finally, a validation process was conducted, in which 50 users were given the system to try it, to later evaluate it. Among the different results obtained, the most important one would be the fact that the system scored an average System of Usability Score of 77.81, with a standard deviation of 14.87. This places the system’s usability well above the standard benchmark of 68.

Full Steriliation Cycle - Master's Intership (10/10)

This project was developed during my internship at Ramón y Cajal University Hospital. Thanks to this, it was carried out in close collaboration with the clinical professionals of the Preventive Medicine Department. It covers the entire sterilization process that reusable clinical materials must undergo before they can be used again. Users will learn how to properly handle this material, as well as how to use the tracking system, which is essential.

Mischievous Die - Project Born of a Personal Initiative

This last project was born of a personal initiative. It is one of the trials of the astronaut selection process of the European Space Agency, and consists on mentally rotating a die. The spanish astronaut Sara García-Alonso describes it in her book "Órbitas", and I thought it would be a fun idea to implement in unity. I've also included a couple of skins to play with different materials.
